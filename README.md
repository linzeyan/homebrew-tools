# homebrew-tools

Homebrew tap and Scoop bucket for installing tools.

## macOS / Linux — Homebrew

Add repository:

```bash
brew tap linzeyan/tools
```

Install:

```bash
brew install ops-cli            # command-line tools
brew install --cask marknote    # desktop apps
```

Upgrade:

```bash
brew upgrade ops-cli
```

## Windows — Scoop

Add bucket:

```powershell
scoop bucket add linzeyan https://github.com/linzeyan/homebrew-tools
```

Install:

```powershell
scoop install linzeyan/ops-cli
```

Upgrade:

```powershell
scoop update ops-cli
```
